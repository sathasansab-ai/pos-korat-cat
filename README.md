# 🐱 POS Korat Cat — All-in-One Retail & Fashion POS

ระบบขายหน้าร้านอัจฉริยะ (Point of Sale) ออกแบบมาเพื่อร้านแฟชั่นที่มีความซับซ้อนของตัวเลือกสินค้า (Matrix Variants เช่น ลายสกรีน DTF, Flex, สี, ไซส์) ผสมผสานความรวดเร็วแบบร้านสะดวกซื้อ พร้อมระบบโปรโมชั่น Mix & Match อัตโนมัติ

---

## 👥 ระบบสิทธิ์การใช้งาน (Role-Based Access Control)

ระบบแบ่งแยกสิทธิ์ชัดเจนระหว่าง **แอดมินหลัก (เจ้าของร้าน)** และ **แอดมินรอง (พนักงานกะ/แคชเชียร์)**:

| ความสามารถ | 👑 แอดมินหลัก (Owner) | 👤 แอดมินรอง (Cashier) |
| :--- | :---: | :---: |
| **รหัส PIN ตั้งต้น** | **`9999`** | **`1234`** |
| ยิงบาร์โค้ด / คิดเงิน / พักบิล | ✅ | ✅ |
| ค้นหาสมาชิก / สะสมแต้ม | ✅ | ✅ |
| เปิดกะ / ปิดกะ / นับเงินสดในลิ้นชัก | ✅ | ✅ (เฉพาะกะตัวเอง) |
| ดูต้นทุนสินค้า (Cost Price) | ✅ | ❌ (ซ่อนทั้งหมด) |
| ดูรายงานกำไรสุทธิ (Gross Profit) | ✅ | ❌ (ถูกล็อค) |
| ยกเลิกบิล (Void Bill) | ✅ ปลดล็อคได้ทันที | ❌ ต้องขอ PIN แอดมิน |
| สร้างสินค้า Matrix (Cartesian Variant) | ✅ | ❌ (เข้าไม่ถึงหน้า) |
| ตั้งโปรโมชั่น Mix & Match | ✅ | ❌ (เข้าไม่ถึงหน้า) |
| เชื่อมต่อ / ส่งออก Google Sheets | ✅ | ❌ (เข้าไม่ถึงหน้า) |

> 💡 **การสลับสิทธิ์:** สามารถกดไอคอน 🔑 บนแถบเมนูด้านบนขวา แล้วใส่รหัส PIN เพื่อสลับสิทธิ์ได้ทันที

## 💻 วิธีการรันบนเครื่องผ่าน VS Code

1. เปิด Terminal ใน VS Code (`Ctrl + ~`)
2. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
3. รันเซิร์ฟเวอร์สำหรับพัฒนา:
   ```bash
   npm run dev
   ```
4. ระบบจะเปิดเว็บที่ `http://localhost:3000`

## 🚀 คำแนะนำเรื่องการ Deploy ผ่าน Netlify (ประหยัด Build Minutes)

> ⚠️ **เนื่องจากโควตา Netlify Build Minutes ของคุณมีจำกัด ขอให้เช็คตาม Checklist นี้ก่อน Push ทุกครั้ง:**

### ✅ Pre-flight Check (ทดสอบใน VS Code ให้ผ่าน 100% ก่อน Deploy)
รันคำสั่งทดสอบ Build และจำลอง Production บนเครื่องของคุณ:
```bash
npm run build
npm run preview
```
- หากรัน `npm run build` ผ่านโดยไม่มีสีแดง แสดงว่า TypeScript และ Bundle พร้อม 100%
- ในโปรเจกต์นี้มีไฟล์ `netlify.toml` กำหนด Single-Page App redirect (`/* -> /index.html 200`) และ Cache Optimization ไว้เรียบร้อยแล้ว จะไม่เกิดข้อผิดพลาด 404 เมื่อ Refresh หน้าเว็บ

### 🌐 ตัวเลือก Deploy แนะนำเพิ่มเติม (ในกรณีต้องการประหยัดโควตา Netlify):
1. **Cloudflare Pages (แนะนำสูงสุด)**: 
   - **Builds ฟรีไม่จำกัด (Unlimited)** และ Bandwidth ฟรีไม่จำกัด
   - เชื่อมกับ GitHub ได้เหมือน Netlify ทุกประการ เหมาะมากหากต้องการเซฟโควตา
2. **Vercel (Hobby Tier)**:
   - ให้โควตาฟรีถึง 6,000 build minutes/เดือน (มากกว่า Netlify 20 เท่า)

## 📱 ฟีเจอร์พิเศษสำหรับหน้าร้าน

1. **จอฝั่งลูกค้า (Dual Monitor):**
   - กดปุ่ม **"จอแสดงฝั่งลูกค้า"** บน Navbar เพื่อเปิดหน้าต่าง `/display` แล้วลากไปยังจอที่สอง
   - อัปเดตรายการสินค้าและส่วนลดแบบเรียลไทม์ 0ms ผ่าน `BroadcastChannel API` โดยไม่ต้องต่อเน็ต
2. **Offline-First Storage:**
   - ฐานข้อมูลทำงานบน `IndexedDB (Dexie.js)` สามารถยิงบาร์โค้ด คิดเงิน และพักบิลได้ตามปกติแม้สาย LAN หลุด
3. **Google Sheets Sync:**
   - ส่งออกไฟล์เป็น `.csv` ที่มีสูตรกำไร (`=J2-I2`) และมาร์จิ้น (`%`) ในตัว รองรับฟอนต์ภาษาไทยสมบูรณ์แบบ
